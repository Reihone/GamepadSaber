# Установка (коротко)

1. Скомпилируй проект в Visual Studio и получи GamepadSaber.dll.
2. Скопируй DLL в папку Beat Saber/Plugins.
3. Запусти игру — в логах появится информация от плагина.

Дальше:
- Для поддержки кастомных мечей потребуется взаимодействие с данными саберов из модов типа NoodleExtensions/Mapping Extensions. Это будет добавлено в следующих коммитах.
